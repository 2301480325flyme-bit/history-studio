# 视觉符号库 + 动画库 v1

> 2026-10-06 · 回应「各种城池的标志 + 动画需要拓展，还有哪些」
> 定位：`ACTION_LIBRARY.md`（AE 时代，3 个动作）的**扩展版**，面向 Remotion。
> 优先级：★★★ = 高频必做，★★ = 中频，★ = 低频/按需。

## 第一部分 · 地点符号库

现状：Remotion 只实现了**圆点**一种（`CityMarker`），AE 侧 4 个 tier。**下面是完整盘。**

### 1.1 行政等级（定居点）

| id | 名称 | 画法 | 优先级 |
|---|---|---|---|
| `capital` | 都城 | 外圈 + 内实心点 + 虚线光环（光环 100–125% 呼吸） | ★★★ 已有 |
| `secondary_capital` | 陪都 / 别都 | 方框 + 内点 | ★★ |
| `seat` | 州治 / 郡治 | 大实心点 + 底部短横 | ★★★ |
| `county` | 县城 | 实心小点 | ★★★ 已有 |
| `town` | 邑 / 聚落 | 更小实心点（低 zoom 时隐藏） | ★★ |

### 1.2 军事设施

| id | 名称 | 画法 | 优先级 |

| `fort` | 戍 / 堡 / 坞 | 小方框 + 内点 | ★★ |

## 第二部分 · 地点状态（同一符号的动态变化）

**这是最被低估、也是最能出效果的部分。** 符号形状不变，靠**状态**讲故事：

| 状态 | 视觉 | 触发时机 | 优先级 |
|---|---|---|---|
| `normal` | 归属色实心 | 默认 | ★★★ |
| `besieged` | 外加**虚线包围环**，缓慢旋转/收缩 | 围城镜头 | ★★★ |
| `fallen` | 点变暗 + **裂纹**（3 条细线） | 城破瞬间 | ★★★ |
| `burned` | 焦黑 + 上方**烟柱**（3 个渐隐圆） | 屠城 / 焚城 | ★★ |
| `abandoned` | **空心虚线** | 荒废 / 迁徙后 | ★★ |
| `newly_built` | 出现时**生长动画**（半径 0→r + 落地涟漪） | 新筑城 | ★★ |
| `renamed` | 旧名淡出 → 新名淡入（**符号不动**） | 建邺→建康、邺→临漳 | ★★★ |
| `upgraded` / `downgraded` | 符号**形态 morph**（县点 → 郡点 → 都城双圈） | 政治地位升降 | ★★ |
| `controlled_by` | **填充色过渡**（旧主色 → 新主色） | 易主（已有 `captureProgress`） | ★★★ 已有 |
| `contested` | **双色对角斜纹填充**，交替闪烁 | 争夺中 / 归属存疑 | ★★ | ← 也解决"疆界存疑"标注

> **`renamed` 是个隐藏杀手镜**：项目里 `world-jin-year-switch.director.json` 已经有"300 年标建邺、400 年标建康"的需求——**同一个点、符号不动、只换字**，比任何特效都有历史感。

## 第三部分 · 动画库（7 层）

现有实现：`useCapture`（攻取四步）、`RouteArrow`（进军箭头）、`CityMarker` 易主过渡、`HistoryShot` 缩放推镜。**其余基本空白。**

### L1 · 事件动词（地图上发生了什么）— 15 个

| verb | 语义 | 参数 | 现有 |
|---|---|---|---|
| `march` | 行军 A→B | actor, from, to, 时间窗 | ✅ RouteArrow |
| `capture` | 攻取城池 | place, actor, from→to | ✅ useCapture |
| `defeat` | 击败 | winner, loser, place | ❌ 待建 |
| `kill` | 斩杀 | killer, victim, stamp | ⚠️ 仅事件卡 |
| `siege` | 围城 | place, actor, 时长 | ❌ |
| `fall` | 陷落 | place, actor, year | ❌ |
| `ascend` | 即位 / 称帝 | actor, title, place | ⚠️ AE 有 |
| `depose` | 废黜 | actor, victim | ⚠️ AE 有 |
| `usurp` | 篡位 | actor, victim | ⚠️ 仅事件卡 |
| `raise` | 起兵 | actor, place | ⚠️ 仅事件卡 |
| `defect` | 叛 / 降 | actor, from→to | ❌ |
| `flee` | 出奔 / 流亡 | actor, from, to | ❌ |
| `enfeoff` | 封王 / 册封 | grantor, grantee, land | ❌ |
| `ally` | 会盟 | parties, place | ❌ |
| `move_capital` | 迁都 | from, to, year | ❌ |

### L2 · 镜头运动（怎么拍）— 8 个

| 手法 | 参数 | 用途 |
|---|---|---|
| `dolly_in` 推 | from/to zoom + focus | 全景→特写，**主力镜头** |
| `dolly_out` 拉 | 同上反向 | 收尾、交代环境 |
| `pan` 摇 | center 水平平移 | 宽幅区域横扫 |
| `track` 移 | center 斜向平移 | 跟随行军路线 |
| `orbit` 环绕 | 需 3D，2D 用**轻微旋转 + 缩放**模拟 | 环视某区域 |
| `crane` 升降 | 用缩放替代 | 2D 无高度维度 |
| `shake` 震动 | 小幅度高频位移 | **攻城 / 决战瞬间**（配合 defeat） |
| `hold` 定格 | 无位移 | 让观众读完字幕（**爆款必备**） |

**铁律**：缓入缓出；一个镜头只做一种主运动；组合的是幅度不是速度；镜头 2–4 秒。

## 第四部分 · 实施优先级（按"性价比"排）

| 批次 | 内容 | 理由 |
|---|---|---|
| **第 1 批** | `capital`/`seat`/`county` 三档行政符号 + `pass`/`ferry` + 状态 `besieged`/`fallen`/`renamed`/`controlled_by` | 覆盖 80% 战争叙事，且 `controlled_by` 已实现 |
| **第 2 批** | `march`/`capture` 打磨 + `defeat`/`kill`/`siege`/`fall` | 战争四件套，直接对应「行军/击败/杀死」 |
| **第 3 批** | `ink_bleed` 墨迹转场 + `dolly_in/out` + `hold` + `shake` | 画面质感与节奏，**差异化点** |
| **第 4 批** | `territory_grow`/`border_flow` + `year_tick` | 疆域变化叙事 |
| **第 5 批** | 第二梯队符号（军事/交通/经济）+ L7 板式 | 按需 |

## 附 · 人物层（另开一节，避免混杂）

符号库只管**地点**。人物是另一套，现有 `KingMarker` 旗标：
- 状态：`active` / `dim_at`（暂离焦点渐暗）/ `out`（退场）
- 动作：`ascend` 金冠 / `depose` 缩 85% / `death` 灰化 + 印章（诛/卒/赐死）
- 待补：`capture`（被俘）、`flee`（出奔，带残影）、`join`（投奔某势力）
