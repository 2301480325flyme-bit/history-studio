# 接下来做什么 · 路线图

> 2026-10-06 · 基于实测的当前状态（不是计划，是诊断）

---

## 一、核心诊断：管线断了两个环

```
二十四史 → 事件抽取 → 分镜生成 → ✂ Remotion 渲染
  ✅通       ✅通       ✅通         ❌断
```

| 环 | 状态 | 具体问题 |
|---|---|---|
| ① 投递 | ❌ **断** | `compile_story.py` 能产出 `director.json`，但 **Remotion 里没有任何地方读它** |
| ② 脚本外置 | ❌ **断** | 7 条镜头的脚本仍硬编码在 `Root.tsx` 的 `const SHOTS: BW[]`，加一集要改代码 |
| ③ 新能力接入 | ❌ **断** | `Symbols.tsx` / `ActionLayer.tsx` 只被验收合成用，**正式镜头还在用旧圆点** |

**① 与 ② 其实是同一件事**：让 Remotion 以 `director.json` 为唯一输入。

## 三、建议的执行顺序

```
P0（打通投递）  →  P1（接入新能力）  →  P4（端到端验证）
                      ↑
              P2 / P3 可并行
```

**理由**：P0 不做完，后面一切都是空转 —— 生成再好的脚本也送不进渲染器。
P0 完成后才能回答「批量到底行不行」这个问题，而那才是这个项目的核心命题。
