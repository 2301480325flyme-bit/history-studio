# 二十四史事件抽取器 · 说明

> `extract_events.py` —— 「批量」的入口。定位不是自动出片机，而是
> **把 3,500 万字缩到几十条候选事件，交给人来审**。

---

## 一、三条设计原则

1. **只扫描，不创作** —— 不做史实判断，不改写原文。
2. **对库校验** —— 抽出的实体必须能命中主表；命中不了的进待审队列。**这是防幻觉第一道闸门。**
3. **不做"智能修复"** —— 正则猜字会把正确内容改错（见第二节实测）。

---

## 二、为什么必须对库校验：一次实测

抽取器在《晋书》里按别名匹配主表人物，命中次数：

| 人物 | 项目当前别名 | 命中 |
|---|---|---|
| 司马伦 | 司马伦 / 赵王 | 414 |
| 司马颖 | 司马颖 / 成都王 | 391 |
| 司马越 | 司马越 / 东海王 | 383 |
| 司马攸 | 司马攸 / 常山王 | 110 |
| **司马炽** | **司马炽 / 河内王** | **4** ← |

对照原文词频：

| 词 | 原文出现 |
|---|---|
| **豫章王** | **13 次** |
| 河内王 | 1 次 |

**项目给司马炽的封号写的是「河内王」，而《晋书》里他封的是「豫章王」**（惠帝纪三处明载）。

> **结论：别名错一个字，抽取命中差 13 倍。**
> 引申：**别名表不是"锦上添花"，是抽取器的命门。** 少一个别名，就等于这个人物的全部内容在成片里消失。

## 三、语料结构缺陷（影响分段）

`二十四史全译05.晋书.txt` 共 99,189 行，但：

- **只有帝纪（纪第一 ~ 纪第十）保留了干净的标题行**
- **志 / 列传 / 载记的卷题在转换中全部丢失**

因此抽取器采用**两段式分段**：

| 情况 | 分段方式 |
|---|---|
| 标题数 ≥ 20 | 按标题分段 |
| 标题数 < 20 | 10 个帝纪按标题，其余按 **800 行等长窗口** |

晋书实际结果：`126 段 = 10 帝纪 + 116 窗口`。

> ⚠️ 这意味着**无法按"卷"精确定位**，只能按"行区间"定位。
> 若后续要按卷引用（如「《晋书》卷五十九」），需要先补回卷题——这是一项独立的数据修复工作。

## 四、动作词表

史书动词 → 事件原语（15 个 verb，见 `视觉符号与动画库-v1.md` L1）。

| verb | 触发词（部分） |
|---|---|
| raise | 起兵、举兵、称兵、反于、叛 |
| march | 伐、征、讨、进兵、引兵、北征、北伐 |
| defeat | 大破、破之、击败、大败、溃 |
| capture | 攻、拔、克、取、据、下之 |
| siege | 围、围城、环攻 |
| fall | 陷落、城陷、失守 |
| kill | 杀、诛、斩、弑、赐死、伏诛、遇害 |
| ascend | 即位、践阼、称帝、称王 |
| depose | 废、幽、废为庶人 |
| usurp | 篡、自立、僭 |
| defect | 降、叛、归顺、以城降 |
| flee | 奔、逃、出走、遁 |
| enfeoff | 封、立为、徙封 |
| ally | 盟、会盟、结盟 |
| move_capital | 迁都、徙都 |

> **一个句子命中越多 verb，事件密度越高** —— 这是排序依据。

## 五、三条命令

```bash
cd "01_工作流/maindata"

# ① 事件密度扫描：找出最值得做视频的段落
python extract_events.py scan 二十四史全译05.晋书.txt --top 30 --out out.json

# ② 实体对库匹配：看主表能覆盖多少
python extract_events.py entities 二十四史全译05.晋书.txt

# ③ 抽取指定段的事件候选
python extract_events.py extract 二十四史全译05.晋书.txt --range 纪第四 --out cand.json
```

## 七、已知局限（诚实说明）

| 局限 | 影响 | 出路 |
|---|---|---|
| 语料有 12,351 处损坏 | 形近字被当成真实实体（`趟王`/`司马通`） | 建形近字纠正表（`text_fixes.json`） |
| 无卷题 | 只能按行区间定位 | 独立的数据修复工作 |
| 无 LLM 接入 | 只做规则抽取，不做语义理解 | 候选交 LLM 做二轮提炼，或直接人工 |
| 无年份抽取 | 未接 `chronology.json` 的年号识别 | 下一步：接入年号 → 公元换算 |
| 实体只有主表覆盖的那 19 个 | 未登记的人物/地名一律漏掉 | 扩主表；未命中候选已输出待审 |

> **一句话：它是"筛子"，不是"作者"。筛出来的东西必须有人过一遍。**
