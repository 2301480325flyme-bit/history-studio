## 二、生产线实际走过的路径

```
① 史料清洗        corpus/晋书.jsonl（8,366 段 / 卷题 136 / 损坏 0.06%）
       ↓
② 事件抽取        extract_events.py --juan 帝纪第四 → 89 条候选
       ↓
③ 实体链接        地点锚定 29.2% → --anchor-only 筛出 94% 有锚点
       ↓
④ 自动分镜        auto_episode.py → 3 集 × 6 镜头骨架
       ↓
⑤ ★人工/AI编辑★   弃用自动主线、从语料补 6 条、写旁白、重排 → 八王之乱-编辑版.json
       ↓
⑥ Remotion        manifest.json 注册（不碰 TS 代码）
       ↓
⑦ 成片            1,464 帧 / 48.85s / 124.63 MB / 21.4 Mbps
```

**全程没有手工写过任何 JSON。** 编辑阶段只做三件事：选事件、删自动结果、写旁白。

## 三、编辑阶段的关键发现（自动化的真实短板）

自动抽取的 26 条有地点候选里，**大多数是李特/张昌的流民起义**，与八王主线无关；
而**八王主线事件（伦篡位、冏起兵、颙表冏、张方入洛、乂被幽、颖奔长安）全部漏掉**。

原因：主线事件要么无地点标注，要么动词未被识别（`篡帝位` 不在动词表里）。

> **这就是「人工/AI 编辑阶段」不能删的原因。**
> 自动化负责"把 89 条排好序铺在地图上"，但**选哪 6 条**是叙事判断，不是检索问题。

编辑动作已记录在 `八王之乱-编辑版.json` 的 `editLog` 字段里，可回溯。

## 四、旁白分工验证

`narrationHint` 作为**证据包**确实好用——写旁白时直接看到：

```json
"verbatim": "癸亥，东海王越执长沙王乂，幽于金墉城，寻为张方所害。",
"year": 304, "era": "永兴元年",
"source": "晋书·帝纪第四", "sourceId": "晋书-p00100"
```

写成字幕的是「城里的宗王开始一个接一个消失。十几年里，洛阳换了八次主人，
而皇帝始终没走出过这座城」——**原文没有被机械改写，只是被读懂后重写**。
每镜的 `narrationHint.note` 里标明哪句是原文、哪句是撰写者的概括。

## 五、验收发现的问题（4 个，都不阻塞）

| # | 问题 | 严重度 | 说明 |
|---|---|---|---|
| 1 | **同位置动作标签重叠** —— 第5镜「执乂」被击杀涟漪圈盖住，文字不可读 | 中 | ActionsStack 同坐标叠放，需要错开或缩涟漪 |
| 2 | **三层底图风格不统一** —— `national` 是新抓的 relief 晕渲（无水系），`wide`/`core` 是老底图（有水系） | 中 | 切换层级时底图质感会跳变 |
| 3 | 字幕两行时第二行居中，排版略怪 | 低 | ShotChrome 的换行策略 |
| 4 | 「冏」字形渲染可疑（可能显示成「冨」） | 低 | 需确认字体是否含该字 |

## 六、两个警告已落成代码约束

### ① CHGIS 层级混淆 → `probe_chgis.py`
我上一轮说「CHGIS 有 49 个**州级** polygon」是**错的**。诊断脚本输出：

```
TYPE_CH = 郡              45 条
TYPE_CH = 非政区国土       2 条
TYPE_CH = 侯国            2 条
TYPE_CH = 州              0 条   ← 一条都没有
```

我把「`pref` 图层里的面」当成了「州」。**照此实施会把郡界画成州界**——
这是那种「看着挺像那么回事」的错。

现在脚本强制输出 `NAME_CH / TYPE_CH / BEG_YR / END_YR / 点数 / 几何类型`，
且结尾自带提示：*「同一图层里可能同时有州与郡，不要把它们统称为州界」*。

### ② unverified 人物不进正片 → `persons_verified` 白名单

不是靠"恰好没用到"，而是**双侧显式过滤**：

| 层 | 机制 |
|---|---|
| Python `MainData` | `persons_verified` = 排除 `fromApproxLayer` 的；近似层强制 `identityStatus=unverified`，否则加载即报错 |
| TS `MainData.ts` | 同样导出 `personsVerified`，注释写明「人物旗标/肖像/阵营必须从这里取」 |
| `check_assets` | 拦截：近似层人物若混入白名单 → 报错；缺 `unverified` 标记 → 报错 |

实测：**29 人中只有 8 人（八王）可进正片**，21 条近似层被拦截。

## 七、项目定位

> **半自动历史地图纪录片生产系统 v0.1**

不是"自动历史视频生成器"。现在能做到的是：

| 能做 | 不能做（也不该做） |
|---|---|
| 从 26 部史书里检出事件候选 | 自动决定"这集该讲什么" |
| 自动锚定地点、自动选底图层级 | 自动写旁白与台词 |
| 生成分镜骨架与时长节奏 | 自动建人物全档（投入大、短期收益低） |
| 保留完整出处可回溯 | 自动确定州界/郡界层级 |

**优先级（按你给的）**：时间 > 地点 > 事件动作 > 人物 > 精细行政边界。
按此，疆域层可以继续推后 —— CHGIS 的西晋数据只有 49 条且**全是郡级**，
本来也用不上；而**人物**等到需要旗标/阵营时再扩。
