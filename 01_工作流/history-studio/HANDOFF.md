## 五、每集的写法（照前几集抄）

`projects/s01e2x-*/episode.yaml` 就是模板：
- 顶部注释：本地语料核对的原文 + "不用：" 列表。
- `notes`：主线问题、反差、细节、动机、演义对照。
- `publish`：hook（≤30 字）、summary、tags、next。
- `beats`：冷开场（1–3 拍）→ 四章（`phase:`）→ 回答主线问题 → 金句 → 一个互动提问 → 下集钩子（`title_bar 下集`）。

流程：
1. `python studio.py sources 关键词 --books 三国志 晋书 --limit 1` 核对原文。
2. `studio.py places …` 查地名，缺的用 `place-add` 入库（写清精度）。
3. 改 `疆域.yaml` 后跑 `consistency.py`。
4. 新说话人登记 `人物声音.yaml`。
5. `studio.py check` → `studio.py build … --build L1`。
6. 用 `studio.py still -t 秒` 抽 2–3 帧看。
7. `publish.py` 生成发布包；在 `launch.json` 加预览。
