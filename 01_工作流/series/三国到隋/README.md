# 系列规格：三国 → 隋（184–589）

参照抖音「白虹说」的节奏（2026-10-08 实测 3 集：154、157、170 秒；横屏 1920×1080；每集一件事，3–5 个章节，每章约 40 秒；上一集结尾就是下一集开头；合集内按"第 N 集"连续编号；约 3–4 天一更）。
只借鉴节奏和结构，文案、画面全部自己写、自己做。

## 一、单集规格

| 项 | 规定 |
|---|---|
| 时长 | **2 分 30 秒 – 3 分钟**（150–180 秒） |
| 字数 | **650–800 字**（按 4.8 字/秒，加停顿） |
| 拍数 | 26–34 拍（每拍 15–35 字） |
| 章节 | **4 章**，每章 35–50 秒、6–9 拍。章名 4–8 字，写进 `phase:`，抖音"章节要点"直接照抄 |
| 时间跨度 | 一集讲一件大事及其直接后果，通常 1–10 年 |
| 标题 | 一句"谁 + 干了什么 + 结果"，例：`曹操迎汉献帝到许县，从此挟天子以令诸侯` |
| 话题 | 5 个：`#三国`（朝代合集名）+ 2 个主角人名 + 1 个事件名 + `#历史` |

## 二、单集结构（4 章）

| 章 | 作用 | 写法 |
|---|---|---|
| 第 1 章 承接 | 15 秒内交代"上回说到"，然后抛出本集的主问题 | 第一句直接接上一集最后的局势，不重讲背景；第二、三句给悬念 |
| 第 2 章 起 | 事件起因、双方实力、关键人物登场 | 数字和地名要准，地图上落子 |
| 第 3 章 高潮 | 决定性的一仗或一次政变 | 动作最密：行军、交战、易手、诛杀 |
| 第 4 章 余波 + 钩子 | 结果和影响，最后 1–2 拍引出下一集 | **最后一拍必须是下一集第 1 章的起点**（新人物登场、新危机出现） |

## 三、连续性规则（"章节之间能够连续"）

1. **剧情连续**：每集的 `next_hook`（最后一拍）= 下一集的 `prev_recap`（第一拍）的内容，大纲里两者成对写好。
2. **地图连续**：每集开场的 `owners`（势力范围）= 上一集结束时的 `owners`。成片开头 2 秒直接从上一集最后一帧的局势开始，不再从空白地图铺开。
3. **年号连续**：年份牌从上一集最后的年份接着走。
4. **人物连续**：已经登场过的人物，后面的集用旗牌和名字，不再重复完整的立绘出场；隔了很多集再出现时，用一句身份提醒。
5. **合集编号**：按朝代分合集（三国 / 两晋 / 十六国 / 南北朝），集号在合集内连续；跨合集的第一集用一句话把读者带过来。

## 四、旁白风格（在 history-narration 规范基础上）

- 白虹说是"编年史密度"：人名、地名、数字很多，很少议论。我们保留这个密度，但每章至少一个"为什么"或反差，避免流水账。
- 每集第 1 章的第二、三句给悬念（本集要回答的问题），第 4 章回答它。
- 演义情节（三英战吕布、草船借箭等）不当史实讲；需要时说"小说里……史书上……"。
- 数字写汉字；人名第一次出现带身份；生僻字按 history-voice 的高风险字表避开。

## 五、制作流程（只写脚本，不渲染）

1. 先写 `分集大纲.md` 里的四章要点、上集承接、下集钩子（本文件夹已备好全部 60 集）。
2. 按大纲逐集扩写成完整旁白（`第NN集-*.md`），每拍附出处；第 1–3 集已写好，作样例。
3. 旁白定稿后，再按 history-storyboard 规范落子成 `01_工作流/projects/<id>/episode.yaml`；构建后用 Remotion 实时预览检查，**用户确认后才渲染**。
