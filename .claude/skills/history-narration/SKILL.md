# 历史地图旁白规范（短视频版）

目标：观众在**前 3 秒**就想知道"然后呢"，后面**每 15 秒**都有一个推进或反转。整片听起来是现代人讲故事，而不是念史书。

## 一、依据：示例视频实测（《两晋南北朝·第一集》）

| 指标 | 示例视频 | 我们旧稿（讨董、官渡） | 目标 |
|---|---|---|---|
| 语速 | **4.8 字/秒** | 3.0–3.2 字/秒 | **4.5–5.5 字/秒** |
| 每句 | 平均 32 字 | 20–25 字 | 15–35 字，长短交替 |
| 每个分句（逗号之间） | 平均 **8.8 字** | 10–14 字 | 6–12 字 |
| 文言原文 | 不直接念；只用"史称""所向披靡"这类书面词 | 屏幕卡片里大量引文 | 旁白里**零引文** |

示例视频的句子骨架：**时间 → 人物 → 动作 → 地点 → 结果**，转折词非常密：但是、紧接着、此后、与此同时、直至、不久。
它的缺点是开头没有钩子，平铺直叙。短视频要在它的基础上**加钩子、加反转**。

## 二、先定故事，再写句子（最重要）

旧稿的通病是**流水账**：按年份一件件交代，"起兵、迁都、打仗、散伙、被杀"，句句是事实，但没有一句让人想追问。写稿前先完成下面四步，写在 episode.yaml 的 `notes` 里。

1. **一集一个主线问题**：用一句话写下观众会好奇的问题，答案放在结尾揭晓。
   - 讨董：十几万大军，为什么干不掉一个董卓？（答案：他们心里算的根本不是董卓；最后杀董卓的是他的干儿子。）
   - 官渡：兵力差好几倍，曹操凭什么赢？
   - 赤壁：曹操八十万大军（号称），怎么一夜之间就输了？
2. **找反差**：同一件事里"预期"和"结果"的落差，就是故事的发动机。比如十几万联军对一个董卓却按兵不动；小说里关羽斩华雄，史书上其实是孙坚；董卓最信任的人亲手杀了他。
3. **找细节**：每一段至少放一个史书原有、能"看见"的细节，比三句概括都管用。原话翻成白话说：
   - 曹洪把马让给曹操："天下可以没有我，不能没有你。"
   - 董卓发脾气，拔出手戟扔向吕布。
   - 吕布喊着"有诏讨贼"，一矛刺死董卓。
4. **给人物动机**：写"他为什么这么做"，而且必须有史据或合理推断（推断要说"恐怕""说白了"）。例如"诸侯们怕的不是董卓，是把自己的兵打光"。

### 情绪弹簧（每段都要有功能）

借短剧编剧的"情绪弹簧"：每一拍要么**压**（制造期待、委屈、疑问），要么**放**（反转、揭晓、打脸），不允许只是交代。写大纲时给每拍标上 `钩 / 压 / 放 / 转 / 收`，连续三拍都是"交代"就要改。

### 开环（小钩子）

每 15–20 秒埋一个"还没回答的问题"，几拍之后回收：
- 埋："按说该冲了吧？" 回收："他们心里算的，根本不是董卓。"
- 埋："只有一个人坐不住。" 回收："曹操。"
- 常用埋法：可问题是……；没人想到……；这还不是最离谱的；答案，藏在……

### 钩子：先写三个，打分选一个

开头第一拍（≤20 字最好）必须让人停下手指。先写 3 个候选，按下表打分，选总分最高的：

| 维度 | 问题 |
|---|---|
| 反差 | 有没有"预期 vs 结果"的落差？ |
| 具体 | 有没有数字、人名、画面？ |
| 悬念 | 听完会不会想问"为什么 / 然后呢"？ |
| 兑现 | 正片里能不能完整回答？（不兑现的钩子是骗点击，禁止） |

常用钩子形状：结果前置（"最后要他命的，是他的干儿子"）、反常识（"十几万人，一仗没打"）、演义对照（"斩华雄的，其实不是关羽"）、数字冲击（"两万打十万"）。

### 结尾：回答主线问题 + 金句 + 下集钩子

最后两三拍先**正面回答**开头的问题，再用一句对仗或反差的金句收住，最后一句抛出下一集的问题。例如："十几万大军没做到的事，一个干儿子做到了。可董卓一死，长安反而更乱了——"

### 禁止

- 连续两拍以年份或"然后、接着"开头（年号牌会自动显示，旁白不必报每一年）。
- 只有概括没有细节的段落（"双方大战，某某大败"之后必须跟一个具体画面或代价）。
- 没有史据的心理描写和对白。

## 三、结构（60–120 秒）

```text
钩子（1–2 句，≤6 秒）  反常识 / 悬念 / 冲突 / 数字
背景（2–3 句）         谁、在哪、为什么，用最快的话交代
推进（主体）           一句一事件；每 3–4 句出现一次"可是 / 没想到 / 就在这时"
高潮 / 反转            最关键的一战、一死、一叛
结果（1–2 句）         谁赢了，地图变成什么样
余韵 / 下集钩子（1 句） "可他不知道……" "真正的乱世，才刚刚开始。"
```

## 四、写法规则

1. **说人话**：
   - 一律用现代口语和常见书面语，不念文言原文。
   - 禁用句式：之乎者也、"卓闻兵起，乃……"、"是时""遂""焉""矣"。
   - 原文摘句只放进 `quote` 字段，供审稿单使用，不进旁白，也尽量不进屏幕卡片。
   - 校验器会提示疑似文言的地方。
2. **钩子模板**（选一种）：
   - 反常识："十几万大军讨伐董卓，结果一仗都不敢打。"
   - 悬念："这一年，有人坐上了皇位，却只坐了一百天。"
   - 演义对照："小说里说是十八路诸侯，史书上可不是这么写的。"
   - 数字冲突："两万对十万，曹操凭什么赢？"
3. **一句一件事**，事件必须能在地图上落点：每句至少点一个画面里有的地名或人名。不要连续两句都没有地点。
4. **节奏**：
   - 长句（25–35 字）后面接一个短句（≤12 字），例如"……迁都长安。洛阳，一把火烧了。"
   - 每 3–4 句至少一个转折词：可是、没想到、偏偏、就在这时、结果。
   - 问句和感叹句每分钟 1–2 个，不要更多。
5. **人名**：
   - 首次出现写成"身份+全名"（渤海太守袁绍），之后用简称。
   - 生僻字和多音字（伷、颙、乂、燮、瓒、邳……）前面带上身份，给配音提供上下文（"豫州刺史孔伷"）。
   - 加了身份还读错的，换一种说法。
6. **数字**：旁白里写汉字（"一百九十年""十几万"），字幕会自动转成阿拉伯数字。年份每段只报一次，避免满屏年份。
7. **不编造**：心理活动、对白、具体数字必须有出处；推测要加"据说"或"史书只记了一句"。演义和正史的差别正好用来做钩子，但要说清"小说里……其实……"。
8. **字幕**：默认自动按分句切成 6–16 字一条，不必写 `caption`。只有想把某个分句换成更短的字幕时，才用列表手写 `caption: [第一条, 第二条]`。

## 五、长度换算

- 60 秒 ≈ 260–300 字 ≈ 10–14 拍；120 秒 ≈ 520–600 字。
- 每拍（一个 `say`）15–35 字，超过 40 字就拆开。校验器会提示。

## 六、改写示例（讨董片原稿 → 新稿）

| 原稿 | 问题 | 新稿 |
|---|---|---|
| 公元一百九十年正月，关东各州郡同时起兵，讨伐专权的董卓。 | 没钩子，平铺 | 十几万大军讨伐董卓，结果——一仗都不敢打。公元一百九十年，关东诸侯同时起兵。 |
| 小说里说是十八路诸侯，可史书上点了名的，其实只有十来家。 | 可以，但偏慢 | 十八路诸侯？那是小说。史书上，点了名的只有十来家。 |
| 他自己留在洛阳，一把火烧掉了宫室。 | 好 | 保留，前面接短句："迁都长安。" |
| 酸枣十几万人马，天天摆酒聚会，不图进取。 | "不图进取"偏书面 | 酸枣的十几万人马，天天喝酒开会，就是不出兵。 |
| 讨董联盟就此名存实亡，一个群雄割据的时代，开始了。 | 好，可以加悬念 | 讨董联盟，就这么散了。而真正的乱世，才刚刚开始。 |

## 七、交稿自查

- [ ] `notes` 里写了主线问题、反差、细节、动机；结尾正面回答了主线问题
- [ ] 钩子写过 3 个候选并打分；开头一拍 ≤20 字
- [ ] 每拍都标得出 钩 / 压 / 放 / 转 / 收，没有连续三拍纯交代
- [ ] 每 15–20 秒有一个开环，且都在后面回收
- [ ] 每段至少一个史书原有的具体细节
- [ ] 前 6 秒有钩子
- [ ] 旁白零文言、零引文，校验器没有"疑似文言"提示
- [ ] 每句都能在地图上落点
- [ ] 每 15 秒左右有一次转折
- [ ] 拍数和字数符合目标时长，配音后实测 ≥4.5 字/秒（见 history-voice）
- [ ] 每拍都有 `sources` 和 `quote`，原文只放在这里

## 八、快节奏版（2026-10-13，抖音数据复盘后用户定）

抖音前三集：2 秒跳出 31–35%，平均只看 29–39 秒，留存全程比同类低 5–10 个点；97% 流量来自推荐页，观众没看过上一集。用户结论："要快节奏，大家不喜欢磨磨唧唧"。
- **冷开场（2026-10-17 复盘修订）**：第一拍用旁白给结果、数字或反常识（「号称八十万大军，怎么一夜之间就输了？」），**不用人物原话开场**。对白开场在抖音数据里 2 秒留存落后同类 7–16 个点，播放只有旁白钩子的 1/8–1/3。人物原话放到第 10 秒以后。不许以「上回说到」开头；回顾压成一句放在 15 秒后（「先说一年前。」）。
- **钩子撑 8–10 秒再揭晓**：悬念不能在第 2–3 秒就给答案；进入背景交代的那一句压到 4 秒内，配镜头或人物切换，不用长句点名人名。
- **片长 2.5–3.5 分钟**：只留打仗、烧城、反转、死人、金句；交代和收尾段能删就删（第 3 集"袁术断粮""联军散伙"章节点击只有 3–4%）。
- **每拍 ≤35 字**，一拍一件事；人物台词只留最狠的一两句。
- **结尾留一个能吵起来的问题**（「如果你是王允，赦，还是不赦？」）。
- 配音：`tempo_target: 5.0`、`pause_cap: 0.2`、`gap: 0.3`、`speaker_min_rate: 5.0`。
