# 地图动画分镜规范

原则：**台词说到哪里，画面就动到哪里。** 示例视频大约每 2 秒就有一处画面变化：新旗牌、箭头伸长、色块扩张、镜头移动、字幕换句。我们的旧片常常一整拍（4–6 秒）画面不动，这是最大的差距。

## 一、示例视频的画面语法（3:20–4:20 逐 2 秒抽帧统计）

- **变化频率**：30 帧里，几乎每帧都和上一帧不同。没有超过 4 秒的静止画面。
- **旗牌**：每个被点名的人或军队，都在事发地立一面小旗。同屏常有 4–8 面，旧的不急着撤。
- **疆域**：每次"攻占、归附、起兵"，色块当场扩张。汉赵的粉色随着叙事一块块长出来。
- **箭头**：进攻、行军用红色，多段折线穿过多个地名；败退、撤离用蓝色；箭头生长和台词里的动词同步。
- **镜头**：先全景建立，再推到战区，跟着事件平移（并州 → 太行山东 → 青州），一个段落结束后拉回。
- **地名**：郡县小字常驻、满屏都是，这是"信息感"的来源。
- **字幕**：按分句切换，平均约 9 字一条。

## 二、"两秒规则"

- 每个分句（逗号之间）至少对应一个画面事件。一拍里有 3 个分句，就要有 3 个事件。
- 用 `cue: 关键词` 让元素在说到这个词时出现，不要都挤在句首：

```yaml
- say: 到了荥阳汴水，迎面撞上徐荣，曹军大败。
  show:
    - arrow:  {from: 酸枣, via: [成皋], to: 荥阳, kind: direction, cue: 荥阳, grow: 1.4}
    - flag:   {at: 荥阳, name: 徐荣, faction: 董卓, cue: 徐荣}
    - battle: {at: 荥阳, title: 汴水之败, cue: 大败}
```

- 局势变化同样可以对准关键词：`owners_cue: 攻占`。
- 镜头也可以：`camera: {focus: 荥阳, zoom: 2.2, cue: 荥阳}`。镜头会提前 0.3 秒开始移动。

## 三、动词 → 画面配方

| 台词里出现 | 画面组合（同一拍内） |
|---|---|
| 起兵、建国、称王 | `flag`（cue 落在人名）+ `owners` 变化（`owners_cue`）+ 城点 `highlight` |
| 进军、南下、西征、直逼 | **首选 `army`**（小兵队列跟着旗走，`banner` 写主将的姓，骑兵 `troops: cavalry`）；`arrive` 对准目的地的词；长途行军加 `follow: true` 让镜头跟着走。只是交代方向时才用 `march` 箭头 |
| 两军交战、遭遇、大战 | **`campaign`**（两方 `sides` 从各自出发地赶来，`clash` 对准"撞上 / 交战"），下一拍写 `rout`（败方溃退）；局部战役用区域底图 |
| 某城被夺、袭取、攻占 | **`takeover`**（原旗退场 → 城点变色 → 晕染 → 新旗 → 回拉），`gain` 只写有史据的州郡 |
| 投降、归附、让出、倒戈、叛变 | **`defect`**（连线指向新主 → 旗牌翻色 → 落字印），verb 用 归 / 降 / 让 / 叛 / 奔 |
| 时间跨越几年、"短短几年后" | **`yearshift`**（镜头不动，年份牌翻页，旧边界留淡影） |
| "与此同时""另一边" | **`meanwhile`**（关系线带着镜头平移到另一地，旗牌入场） |
| 重要人物登场后立刻行动 | `enter` 加 `settle: true`（立绘收成驻地旗牌），下一拍从这里 `army` 出兵 |
| 几路同时出兵、诸王并起 | `multi_march`（`routes` 列出各路） |
| 围、攻、困守 | `siege`（围 / 攻 / 急） |
| 败走、出奔、溃逃 | `flee`（蓝色细断箭头，1–1.5 秒） |
| 某城易手、被夺 | `capture`（城点换色加"易手"）+ 需要时同拍改 `owners` |
| 会盟、合兵、联合 | `alliance`（多点连线汇向会盟地） |
| 总结路线（"颖自邺南下……"） | `replay` 路线回放 |
| 强调某地 | `spot` |
| "此时天下归谁" | `breathe`（势力疆域呼吸） |
| 击败、大破、击溃（没有交代双方来路时） | `battle` 在战地（cue 落在"败 / 破"）+ `rout` 败方溃退 |
| 杀、诛、斩、车裂 | **`act: execute`**（手绘刀痕 + 墨点 + 毛笔大字，默认墨色；极少数大案才写 `tone: red`）；人物有旗牌时同拍写 `exit` |
| 病死、卒 | `exit`（旗牌下沉变灰 + 朱印"卒"） |
| 迁都 | `arrow kind: recorded`（附 evidence）+ 新都城点高亮；驱民西迁加 `act: refugees` |
| 诏书、下令、改制、赦免 | `act: edict`（黄绫展开写字） |
| 登基、称帝、即位 | `act: enthrone`（祥云金框罩立绘） |
| 驾崩、国丧 | `act: mourn`（全画面褪色 + 丧幡 + 黑带大字） |
| 卖官、赋税、赏赐、财政 | `act: coins` |
| 下狱、押送 | `act: prison`（囚车） |
| 告密、送信、送首级 | `act: courier`（驿骑沿虚线跑） |
| 各地响应、告急、烽火 | `act: beacon`（烽火台依次点燃） |
| 放箭、伏击 | `act: arrows` |
| 诱敌、放牛马 | `act: herd` |
| 架浮桥、夜渡 | `act: pontoon` + 同拍 `army` |
| 最惊险的一刻（举鞍挡箭、火船冲营） | `vignette` 情景插画窗（每集最多一两处） |
| 火攻、焚城 | `fire`（交战中的火攻挂在 `clash` 上，只烧败方人群） |
| 水淹、决堤、灌城 | `act: flood` |
| 夜袭、连夜 | `act: night`（`places` 写哪几处举火把） |
| 大风、风向 | `act: wind` |
| 雷、天象异变 | `act: thunder` |
| 投石、霹雳车、攻城器械 | `act: catapult` |
| 蝗灾、饥荒 | `act: locusts` |
| 城破、城陷 | `act: fall`（断墙 + 浓烟） |
| 屯田、积谷 | `act: farm` |
| 玉玺、虎符、冕冠、营寨、关隘、宫殿、帝陵、会盟坛、宴饮… | `act: prop`（`item:` 写名字，见第八节） |
| 换章、大段落开始 | `act: inkwash`（墨晕铺满再散开，`text` 写章名），每集 0–2 次 |
| 结盟、联合、归附于某人 | `arrow kind: relation` 连接两面旗 |
| 重要人物首次出场、重新登场 | `enter` 立绘（3.5–4.5 秒，`at` 连到据点），全片 3–5 次 |
| 地图上频繁切换人物 | `person_card`，轻量人物卡（3–4 秒） |
| 某方发难、响应、掌权 | `faction_bar`（cue 落在动词），可以叠放 2–3 条 |
| 对抗、联盟、废立、内斗 | `versus`，中间字印用讨 / 盟 / 废 / 斗 |
| 被杀、被囚、兵败、逃亡、病死 | `exit`（旗牌自动下沉变灰并落印章，重要人物加 `portrait: true`） |
| 关键事件命名（篡位、入洛、返洛） | `title_bar`，顶部居中（约 3 秒） |
| 原文点睛（全片 1–2 次） | `quote` 引文卡（旁白仍用白话讲） |
| 段落转折、一战定局 | `headline`，全片 1–3 次 |
| 史实辨析（演义 / 正史） | `card`，左上角，不超过 4 秒 |
| 年份变化 | 拍上写数字 `year: 301`，自动显示"永宁元年 / 公元301年" |

### 人物表 `people`（全片一次声明，处处引用）

```yaml
people:
  赵王伦: {person: sima_lun, display: 赵王伦, title: 宗室, role: 控制洛阳, faction: 赵王, base: 洛阳}
```

- `person` 对应 maindata 人物 id，有立绘就自动带上。
- `image` 可以直接指定立绘文件（放在 `projects/<id>/` 下）；带透明背景的 PNG 会自动按真立绘方式浮在地图上。
- `faction` 决定阵营色。
- 没有立绘的人物，自动改用文字印章卡。

完整组件见网页 Studio 的「组件库」页，或 `01_工作流/history-studio/components.json`。

## 四、镜头编排

| 层级 | 缩放（`scale` 约 3500 的全国底图） | 用途 |
|---|---|---|
| 全国 | 0.6–0.8 | 开场、局势总览、结尾 |
| 区域 | 1.0–1.6 | 一州或几州，介绍某方势力 |
| 战区 | 2.0–3.0 | 一场战役、一条进军线 |

- 每 6–12 秒至少有一次镜头移动（推、拉、平移）。同一个焦点不要停留超过 10 秒。
- 段落结构：全国（建立）→ 推进到区域 → 跟着事件平移 → 段落末拉回全国。
- 讲边地势力（交州、辽东）时，用 `shift` 把它们移出字幕条的遮挡区。
- 没写 `camera` 的拍会自动跟随本拍涉及的地点。关键拍要手写，并用 `cue` 对准地名。

## 五、信息密度

- 割据题材打开 `territory.jun_labels: always`，郡名常驻，复刻参考片的满屏地名。
- 旗牌同屏 4–8 面是正常的。`until` 用来控制退场，不要一拍一清空。
- 说明卡同屏只能有一张。肖像、大标题出现时，不要同时弹出卡片。
- 每个势力固定颜色（`palette.json` 的色位），主角加 `main: true`。

## 六、验收（必须亲自看）

1. `studio.py still <yaml>`：看每拍的中点帧，检查遮挡和焦点。
2. 抽连续帧检查静止段（渲染后）：

```powershell
ffmpeg -ss 0 -t 60 -i 成片.mp4 -vf "fps=0.5,scale=480:-1,tile=6x5" -frames:v 1 motion.jpg
```

   相邻两格完全相同的，就是静止段。连续两格以上相同（≥4 秒），必须补画面事件。
3. 检查清单：
   - [ ] 每个分句至少一个画面事件，关键动作都用了 cue 对准台词
   - [ ] 每次控制权变化都有 `owners` 动画
   - [ ] 没有超过 4 秒的静止画面，没有超过 10 秒不动的镜头
   - [ ] 被点名的人物和军队都有旗牌，进军都有箭头，战斗都有战事标记

### 比例尺
局部战役（几百公里内，如汴水、官渡、赤壁）要用区域底图：`map.scale` 约 9000，`extent` 只框相关几州。全国底图上，小兵队列会挤成一团看不清。全国大势和局部战役分成两集或两个段落来做。

## 七、目前引擎做不到的（不要假装做到）

两处战场分屏再合成（会师、夹击用两个镜头同时看）、边界线流动描边、3D 地形倾斜、云梯攻城的细节动画、战船编队在水面上航行和火船冲阵（战船目前只能作为 `prop` 静物出现）。需要的话，先提出来，再扩展引擎。

## 八、手绘动作库 `act`（2026-10-10，素材在 `03_素材/动画素材/第1–3批`）

所有动作都是 `show` 里的一项，支持 `cue / delay / for / until`；`text` 是动作旁边的毛笔字标签（2–4 字），可以不写。

| 动作 | 写法 | 位置参数 |
|---|---|---|
| 处斩 | `act: {act: execute, at: 洛阳, text: 诛, cue: 砍死}` | `at`；`tone: red` 仅用于极少数大案 |
| 诏书 | `act: {act: edict, at: 洛阳, text: 赦, sub: 解除党锢}` | `at`，`side: left/right` |
| 登基 | `act: {act: enthrone, who: 刘协, title: 汉献帝, text: 九岁即位}` | 无地点，`who` 用人物表 |
| 驾崩 | `act: {act: mourn, text: 崩, sub: 中平六年 · 四月}` | 无地点 |
| 卖官 | `act: {act: coins, at: 洛阳, text: 卖官}` | `at` |
| 下狱 | `act: {act: prison, at: 广宗, text: 下狱}` | `at` |
| 信使 | `act: {act: courier, places: [巨鹿, 洛阳], text: 告密}` | 两地 |
| 烽火 | `act: {act: beacon, places: [甲, 乙, 丙…], text: 响应, step: 0.3}` | 多地，依次点亮 |
| 箭雨 | `act: {act: arrows, places: [射手处, 目标], text: 伏击}` | 一地（从左上方射来）或两地 |
| 放牛马、惊群 | `act: {act: herd, places: [从, 往], n: 12, text: 放牛马}` | 两地；牛和散马从第一地冲向第二地，边跑边散开（第9批素材） |
| 浮桥、架桥渡河 | `act: {act: pontoon, at: 渡口城, angle: 行军方向°, len: 110, offset: [x, y], text: 浮桥}` | 小船一节节铺过河面；`angle` 对准行军路线，`offset` 把桥挪到城外的河上；配同一拍的 `army` 走过去 |
| 情景插画窗 | `vignette: {image: illus_xxx, cue: 关键词, for: 5, text: 一句标题}` | 地图上开一个羽化椭圆窗，插画缓慢推近，周围地图压暗；图放在 03_素材/动画素材/第N批/illus_*.png，按第10批任务单请 Codex 画 |
| 水淹 | `act: {act: flood, at: 下邳, text: 水淹下邳}` | `at`，`radius` 放大水面 |
| 夜色 | `act: {act: night, places: [乌巢], text: 夜袭}` | 可无地点；`places` 处点火把 |
| 狂风 | `act: {act: wind, at: 长社, text: 大风}` | `at`，`dir: left` 反向 |
| 雷电 | `act: {act: thunder, at: 长安, text: 天象异变}` | `at` |
| 投石车 | `act: {act: catapult, places: [官渡, 袁营], text: 霹雳车}` | 两地（车在第一地） |
| 蝗灾 | `act: {act: locusts, at: 兖州某城, text: 蝗灾}` | `at` |
| 城陷 | `act: {act: fall, at: 寿春, text: 城破}` | `at` |
| 流民 | `act: {act: refugees, places: [洛阳, 长安], text: 迁都}` | 两地 |
| 屯田 | `act: {act: farm, at: 许, text: 许下屯田}` | `at` |
| 器物/地标 | `act: {act: prop, at: 洛阳, item: 玉玺, text: 传国玉玺}` | `at`，`size` 缩放 |
| 墨晕转场 | `act: {act: inkwash, text: 官渡之战, sub: 第三章, for: 3}` | 无地点 |

`prop` 的 `item` 可选：玉玺、虎符、冕冠、铜钱、粮仓、书信、竹简、城门、楼船、小船、烽火台、囚车、投石车、断墙、营寨、城池、宫殿、关隘、桥、帝陵、会盟坛、宴饮、酒瓮、御座、爵、战鼓、火把、箭、惊马、剑、朝履、节（符节）、印绶、赤帻、望楼、蜜水碗、衣带诏、草庐（茅庐）、马车、手戟、绳索（缚绳）、粮车（辎重）。

`act: {act: jianlv, at: 洛阳, cue: 佩着剑, for: 5}`：剑履上殿专场（压暗地图、宫殿虚影、剑落地、朝履三步走入）。人物 `speaker` 台词自动垫 caption_plate 纸底、立绘旁出墨气线，不用另写。

`act: {act: feint, at: 洛阳, text: 洛阳城, sub: 董, n: 2, color: '#6f4a8e', cue: …, for: 7.5}`：疑兵计专场（城池居中；夜里少数骑兵悄悄出城，白天大队打旗入城，重复 n 回）。两地相距太近、地图上看不出往返时，用这种专场代替 army 箭头。
近距离事件（十几公里内）镜头可用 `zoom` 到 30（例：小平津→北邙 用 28），配 `act: night` 表现夜行。

人物台词节奏（引擎自动）：`speaker` 台词实测低于 4.3 字/秒会自动提速（最多 1.35×，可在 voice 里用 `speaker_min_rate` 改）；
单句仍嫌慢就加 `pause_cap: 0.15` 缩短句内停顿，或直接写 `speed`。某句太响（哭诉、临终）用 `gain_db: -5` 压低，不改 style——改 style 会重新合成。

军队兵种：`army` / `campaign` / `clash` 的 `troops` 可以写 `cavalry`（骑兵，主将骑马领头）、`infantry`（盾戟步兵）、`archer`（弓手）、`crossbow`（弩手）。士兵是手绘兵俑，脚下圆斑是阵营色。

`headline` 自动压在墨色笔刷上，`title_bar` 压在朱砂笔刷上，`card` 底边是宣纸毛边，不用另写。

用法原则：
- 动作替代单字印章。能用动作讲清楚的，不再只盖一个字。
- 一句台词一个主动作就够，最多再配一个人物出场或旗牌；同屏手绘动作不超过 2 个。
- 演示和样例：`01_工作流/projects/zz-acts-painted/episode.yaml`（每个动作各演一遍）。

## 九、音效 `sfx`（可选，AI 自行判断）

- 词表在 `03_素材/音效/cues.json`，约 57 个词条，每条写明"什么时候可以用"。任何 `show` 项都可以加 `sfx: 词条名`，或者单独写一项 `- sfx: {name: 词条名, cue: 关键词}`。
- 不是每个动作都要配音效：一句话最多一个点缀音；大战才用铺底（交战、战鼓铺底），铺底最长 8 秒，说话时自动压低。
- 同一个音 6 秒内不重复，10 秒内超过 4 个会给出警告。
- **两军厮杀不用人声**（2026-10-15 用户：喊杀叫声太难听）：不用 `喊杀`、`交战`（人群叫喊），一律用 `刀剑交击`（接战）或 `兵器碰撞`（小规模交手）、`刀剑`。
- 常用搭配：片头 `片头鼓`；人物登场 `登场`；帝王登场 `帝王登场`（编钟+大鼓，原创合成）；处斩 `处斩`；诏书 `诏书`；卖官 `钱币`（原创合成）；退场 `退场钟`；火攻 `火攻`、`点火`；行军 `骑兵行军`/`步兵行军`（`len: 6`）；交战 `刀剑交击`、`兵器碰撞`；疆域易手 `疆域易手`；时代转折 `时代转折`。
- **引擎自动补的音（2026-10-28 起，不用手写）**：
  - 交战（`battle`、`clash`）在前后 1–2 秒内没有任何音效，自动补一声 `刀剑交击`；6 秒内连着两仗，依次换成 `兵器碰撞`、`挥刀`，免得第二声被冷却规则吞掉。
  - 围城（`siege`）补 `战鼓`，火攻（`fire`）补 `火攻`。
  - 疆域变色时 1.5 秒内没有音效，补 `疆域易手`；只加斜纹不出声。
  - 立绘退场补 `退场钟`，钟声对准退场那个词。
  - 剧本里自己写了音效的，以剧本为准。
- 新音效先放进 Studio「音效」页让用户试听，同意后才写进 cues.json。

## 十、人物亲口说（`speaker`，2026-10-10）

关键时刻让历史人物自己开口，而不是旁白转述。整句单独成一拍，用这个人物自己的声音读：

```yaml
people:
  张角: {image: 03_素材/人物立绘/zhang_jue.png, title: 太平道首领, faction: 黄巾,
         voice: 一位四十多岁的东汉方士、太平道首领，男声，嗓音浑厚有力、略带沙哑，带着宗教领袖的狂热与号召力}

beats:
  - say: 他们喊出一句口号：          # 旁白引出（以冒号结尾即可）
  - say: 苍天已死，黄天当立！岁在甲子，天下大吉！
    speaker: 张角
    style: 振臂高呼，狂热激昂，像在万人集会上向信徒呼喊
    sources: [hhs-71]
```

- 人物的声音按 `people.<名>.voice` 的描述用 MiMo 音色设计做一次，存在 `03_素材/配音参考/人物/`，以后各集同一个人都是同一个声音；改描述就会重新设计。
- 这一拍自动：立绘入场（本拍没写 `enter` 时），字幕显示金色人名和「」引号，配音和旁白同样响度、略带一点空间感。
- **只用有史料出处的原话**（如张角口号、曹操"宁我负人"见裴注等），白话化可以，但不编造。演义台词要么不用，要么在旁白里先说"小说里……"。
- 一集 1–3 处就够，留给最有戏的时刻；每句不超过 30 字。
- **要有激情就给激昂的声音样本**：克隆会模仿样本的语气。样本默认是一句平静的话，张角喊出来就是平的。激昂的人物在 people 里加 `voice_sample: 弟兄们！这世道没有活路了，随我起事！`，`voice` 描述里写"说话激昂亢奋、声音洪亮"。
- 语气标签写在 `voice_text`（只给配音用，字幕仍显示 `say`），标签要短：`voice_text: （激动地高喊）苍天已死！黄天当立！（振臂高呼）岁在甲子，天下大吉！`。标签太多会拖慢。
- `speed: 1.15` 让这一句快一点（句内停顿先压到 0.25 秒，再整体加速，音高不变）。
- 第 1 集张角口号的写法可以照抄（`01_工作流/projects/s01e01-huangjin/episode.yaml`）。

## 十二、对话舞台与死亡变灰（2026-10-12，学安州牧《两晋十六国》）

- **对话舞台**：连续 ≥2 句人物台词（中间可夹以"："结尾的旁白引子）自动离开地图，进古籍纸舞台：两人大立绘左右对站，说话者亮、听者暗，台词以毛笔字逐字写出。
  - 说话人换了阵营（`people.faction` 不同）自动另起一个舞台，避免"袁绍帐下的人对着曹操的谋士说话"（2026-10-14 毛玠/淳于琼）。同阵营但不在同一场合（如洛阳的曹丕冷笑、军帐里的陆逊训将）要手动隔开：在中间那句写 `scene: none`。
  - 台词拍写 `quote: 原文`（必须查过本地史料）就显示原文并标"史书原文"，底部字幕仍是白话；不写 quote 就把白话写成毛笔字，底部字幕自动省掉。

  - 舞台里该人物的 enter / versus 会被自动去掉；含行军、交战、旗牌等地图元素的拍不会进舞台。
- **死亡变灰**：`exit: {who, verb: 斩, portrait: true, side: left}`——大立绘停一瞬后 0.6 秒褪灰；斩/诛带红色刀痕，其余为淡墨晕开。
- **人物朝向**：立绘统一是"脸朝画面右侧"的四分之三侧身。引擎自动让站在右边的人（enter `side: right`、对峙卡右方、对话舞台右位、死亡立绘）做镜像，两人面对面。不宜镜像的（如带眼罩、单侧标志物）在 `people` 里写 `faces: front` 关掉；真朝左的写 `faces: left`。
- **说话必有立绘**：人物开口时他的立绘会自动撑到这句说完；构建时若某句台词画面上不足 80% 时间有他的立绘，会报"画面上却只有 X% 的时间有他的立绘"。
- **场景底图**：`scene:` 可写 军帐/朝堂/城楼/辕门/楼船/草庐/宴席/刑场/宫门（及别名，见 studio.py `SCENES`），素材在 `03_素材/动画素材/第6批`。

## 十六、行军逻辑与交付前逐拍自查（2026-10-19～23，潼关之战、逍遥津复盘，必须执行）

**行军逻辑（引擎已支持，见 SCRIPT.md「行军与驻扎」）**
- 每支要交代去向的部队都写 `head: 人名`（有立绘）或 `unit: 部队名`。写了名字，引擎就会：到达即扎营（帐篷 + 名字）、出发即拔营；2026-10-28 起默认不留来路虚线（行军箭头已经交代了路线，用户认为多余），只有路线本身是看点的长途行军（如千里奔袭、北伐出祁山）才写 `trail: true`，虚线在到达后两拍淡出；`check` 会报「从他此刻不在的地方出发」「没有行军就换了地方」「溃散后又出现」。

  - 屯驻：讲到的屯兵地要有营帐或旗。
  - 交战：讲到的交战地要有 battle / clash / tactic。
- 每一拍写它讲了账上哪几件事：`tells: [e29, e30]`。标了的必须画出来；没标的只查疆域。旁白提到了某件事的地名却没有哪拍标它，会给警告，不画就在账里那条写 `skip: 理由`。
- 标了但确实不画的，在那一拍写 `campaign_skip: {e07: 理由}`，理由进审稿单。
- 没有账的集，`check` 只给警告「有行军却没有战事.yaml」；旁白里有「投降、攻下、拿下」加地名而疆域没动，也给警告（`territory_hold: 理由` 可免）。
- 审稿单 `review.md` 会多一节「战事账对照」：每件事 → 哪一拍讲到 → 画了什么。交付前逐条看。
