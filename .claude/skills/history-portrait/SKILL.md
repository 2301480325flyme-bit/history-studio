# 历史人物立绘（History Studio）

立绘的作用是让观众一眼认出这个人。所以每张图必须带一个**有史料出处的标志**：一件道具、一个动作或一种神态。不要只画成"穿官服的中年男子"。

例子：张角手持九节杖和黄符；袁术手捧传国玉玺；司马懿身体朝前、脸回望身后（狼顾）。

## 一、固定规格（不许改）

| 项 | 要求 |
|---|---|
| 格式 | PNG，**透明背景**（必须有 alpha 通道） |
| 尺寸 | 1024×1536，竖版 2:3 |
| 构图 | 头顶到腰部的半身像，略仰视；头部高度约占画面 1/5；头顶留白 5–8%；左右各留约 5%，**道具和袖子都不能出画** |
| 朝向 | 3/4 侧身，默认面朝画面右侧。需要朝左时单独生成，**禁止镜像翻转**（汉服右衽，镜像后会变成左衽） |
| 画风 | 中国古代工笔人物画，绢本设色；赭石、朱砂、石青、墨色；全系列统一 |
| 禁止 | 可读的文字、印章、边框、水印、背景场景、地面阴影、火焰烟雾等大面积特效、现代元素；不参考真人照片 |
| 道具上的字 | 玉玺印面朝下或侧对观众，诏书和竹简只画墨线，符纸只画抽象的朱砂符纹，**不出现可读的汉字** |
| 冕旒 | 只有已经称帝的人物才戴（立绘取称帝后的形象时） |
| 命名 | 拼音 id，例如 `zhang_jue.png`；放到 `03_素材/人物立绘/` |

## 二、人物分级：主角画"定妆像"，配角画"典故像"或"身份像"

动笔前先给人物定级，两级的画法不一样。

| 级别 | 判断 | 画法 |
|---|---|---|
| **主角** | 跨 3 集以上，或者是一方君主、核心人物（三国里如曹操、刘备、孙权、诸葛亮、司马懿、关羽、张飞、袁绍、董卓、周瑜） | **定妆像**：只画这个人在全系列都不变的特征，不拿某个场景的道具 |
| **配角·有名典故** | 只在 1–2 集出场，且有家喻户晓的典故（第三节评分：知名度 ≥ 2、可画性 ≥ 2） | **典故像**：用这个典故做主标志（见第三节） |
| **配角·无名典故** | 只在 1–2 集出场，没有普通观众叫得出的典故（如朱儁、韩馥、徐荣） | **身份像**：不拿典故道具，靠身份、年龄、配色、兵器或冠帽区分（见第三节之二） |

### 主角的定妆像

主角要在几十个镜头里反复出现，所以图要有**辨识度**，但不能把人锁死在某一个故事里。

- 靠**稳定特征**认人，每人选 2–3 项，并且和其他主角都不重复：
  - **史载外貌**：刘备"垂手下膝，顾自见其耳"，关羽美髯，孙权"方颐大口"、紫髯（注）。
  - **固定配色**：每个主角一个专属主色，全系列不改，比如曹操玄黑、刘备赭红、孙权绛紫配金。
  - **冠帽和剪影**：武冠、进贤冠、纶巾、头巾，以及体型、须式。
  - **气质**：要符合史书评价，比如曹操"深沉果决"、刘备"宽厚"、司马懿"内忌而外宽"。
- 道具只用**伴随一生、不指向单个场景**的东西：诸葛亮的羽扇、关羽的长柄刀（演义）可以；曹操的断发、刘备的草席不行。
- 身份变化大的主角，可以按时期**分版本**，文件名加后缀，各集脚本里引用对应版本：
  - `cao_cao.png`：标准像，用于讨董到官渡。
  - `cao_cao-wei.png`：魏王时期，可以戴远游冠、穿王服。
- 想在某一集用典故场面，另出一张**场景变体** `<id>-<典故拼音>.png`，例如 `cao_cao-gefa.png`。变体只在那一集里用，不替换标准像。
- 主角的人物卡第一行写"稳定特征"，不写典故名。

## 三、配角：先找典故，再考据（顺序不能反）

配角出场少，立绘要画的是**观众记得的那个故事**，不是这个人的官职。判断标准只有一条：

> **看图的人能不能说出一个典故名？** 比如"乐不思蜀""白衣渡江""割发代首""单刀赴会"。

**说不出来，就不要硬画典故**——改画"身份像"（下面第三节之二）。2026-10-08 教训：朱儁没有名典故，硬套"攻宛城"画出一架攻城梯；卢植"槛车征"画成身前一排木栅栏。观众认不出故事，只觉得奇怪。宁可画一个干净、可信的人物，也不要一个莫名其妙的道具。

### 第 1 步：列典故（先别查史书）

每个人先写出 3–5 个候选**名场面**，从这些地方找：
- 成语和俗语：刮目相看、乐不思蜀、司马昭之心、望梅止渴、髀肉复生……
- 名场面：三顾茅庐、长坂救主、白门楼、单刀会、火烧连营……
- 外号和传说：白眉马良、锦帆甘宁、虎痴许褚、盲夏侯、羊陆之交……
- 《三国演义》回目、百度百科"典故"一节、中学课本。

### 第 2 步：打分选一个

| 维度 | 问题 | 分值 |
|---|---|---|
| 知名度 | 普通抖音观众听过吗？ | 0–3 |
| 可画性 | 半身像里，靠一个道具或一个姿势就能表现吗？ | 0–3 |
| 唯一性 | 和"已用标志"表撞了吗？撞了直接 0 分 | 0–2 |
| 史实级别 | 史 3 ／ 注 2 ／ 世说等 1 ／ 演义 0（演义只在家喻户晓时才用，必须标注） | 0–3 |

取总分最高的那个。**知名度 < 2 或可画性 < 2 的不选**，史料再扎实也不选——这时改画身份像（第三节之二），不要凑。

### 第 3 步：考据核实

再用 `python 01_工作流/history-studio/studio.py sources <关键词> --books 三国志 后汉书 晋书` 查本地二十四史。裴注不全的话，查维基文库，找到原文出处。

来源分级：
- `史`：正史正文。
- `注`：裴松之注、李贤注。
- `世说`：《世说新语》等杂史笔记。
- `演义`：《三国演义》、戏曲。

### 第 4 步：落到画面

- 把典故**翻译成一个道具或一个姿势**：
  - 乐不思蜀 → 举杯含笑
  - 白衣渡江 → 商贾白衣下露出甲片
  - 割发代首 → 一手持剑、一手握一束断发
- 只画一个主标志，最多再加一个辅助特征。
- 每人定一个**主色**。同一集里同框的人物主色要拉开，全系列不能都是"红配藏青"。
- 剪影要不同：冠帽、须发、身形、持物位置，至少有一项明显不一样。

### 三之二：身份像（没有名典故的配角）

- 画这个人**在故事里的身份**，让观众一眼分得清：武将 / 文臣 / 宦官 / 外戚 / 宗室 / 黄巾 / 少数民族首领……
- 区分手段按优先级：**身份服制与冠帽 → 年龄和体型 → 专属主色 → 合乎身份的随身物**（武将持本人惯用兵器、佩剑或握缰绳；文臣持笏或手按腰带；宦官垂手、无须）。
- 姿态要自然：站姿、按剑、拱手、回望都行；**不要表演某个场景**（不扛梯子、不站在栅栏后、不端着碗、不举火把）。
- 人物卡第一行写"身份像：【身份】"，不写典故。

### 道具合理性（所有立绘都要过）

1. 这件东西**一个人在半身像里会自然拿着**吗？兵器、扇、笏、书卷、印、杯、拂尘可以；梯子、门、笼子、车、栅栏、桌案、大件建筑构件不行。
2. 缩到 200 像素宽，**还看得出是什么**吗？看不出就去掉。
3. 不认识这段历史的人看到，会**觉得奇怪**吗？会，就去掉。
三条有一条不过，改画身份像。

### 禁止当主标志的东西

下面这些写进人物卡，人物卡就作废：
- "身份服制""帝王礼服""朝服冠冕"：这是身份，不是典故。
- "视觉概括""象征其战略"：说明没找到典故，回到第 1 步重新找。
- 泛用的地图、文书、奏牍、书卷、印、笏：除非就是这个人的专属典故（袁术的传国玺可以）。
- 只写神态（"神情坚毅""目光深沉"）。

## 四、人物卡格式（写进该系列的立绘清单 md）

```
### 刘禅 `liu_shan`
- 典故：乐不思蜀（注：《三国志·后主传》注引《汉晋春秋》"此间乐，不思蜀"）
- 候选与打分：乐不思蜀 3+3+2+2=10 ✓；扶不起的阿斗 3+1+2+0=6；捧玺出降 1+3+0+3=7
- 画面：体态丰腴，一手举酒杯，笑容轻松，毫无亡国之忧
- 主色：杏黄
- 时期：263 年降魏后，约五十岁
- 朝向：右
```

配角卡的**第一行必须是典故名**，写不出就不许进入生图。主角卡的第一行写稳定特征，例如：

```
### 曹操 `cao_cao`（主角 · 标准像）
- 稳定特征：身形不高、目光锐利、短须；玄黑主色；武冠（史：《三国志·武帝纪》注引《曹瞒传》"为人佻易无威重"、《世说》"形陋"，取其短小精悍）
- 与其他主角的区分：刘备赭红、长臂大耳；孙权绛紫、紫髯；袁绍金黄、雍容
- 道具：腰佩长剑（不指向具体场景）
- 版本计划：cao_cao.png（讨董到官渡）、cao_cao-wei.png（魏王时期）
- 朝向：右
```

## 五、提示词模板（套进人物卡后，整段发给 GPT）

```
生成一张中国【朝代】时期人物的半身立绘。
人物：【人物·时期形象】，【外貌】，【服饰】，神态【神态】。
典故：【典故名】——画面为【具体到哪只手、拿什么、什么姿态】；【辅助特征】；主色【主色】。道具完整地画在画面内。
风格：中国古代工笔人物画，绢本设色质感，线条细腻清晰，色调沉稳（赭石、朱砂、石青、墨色），与同系列人物统一画风。
构图：头顶到腰部的半身像，略仰视，3/4 侧身面朝画面【右/左】；左右各留约 5% 空白，袖子和道具不贴边；头顶留少量空白，头部高度约占画面五分之一。衣襟为右衽。
背景：完全透明（PNG 透明背景），不要场景、地面、阴影、火焰烟雾。不要任何可读文字、印章、边框或水印；道具上的文字用抽象纹样代替。
尺寸：1024×1536 竖版。
```

## 六、批量生成（Codex 可以自动出图）

- 人物名单看该系列的清单文件，例如 `03_素材/人物立绘/三国立绘/三国-提示词.md`。按优先级逐档往下画：必需 → 可选 → 扩展。
- 每个人：考据 → 写人物卡 → 套提示词模板 → 生图 → 验收 → 保存为 `03_素材/人物立绘/<id>.png` → 登记。
- 如果生图工具不直接支持透明背景，就先生成纯色背景（例如纯绿），再抠图转成 RGBA；抠完检查四角透明、边缘没有绿边。
- 同一系列要保持画风一致。每批开始前，先看两三张已有立绘作为风格参照。

## 七、交付与验收

- 生成后检查以下几项，任何一项不合格就重新生成：
  - alpha 通道存在，四角透明（`python -c "from PIL import Image;im=Image.open(p);print(im.mode,im.size,im.getpixel((0,0)))"` 应输出 `RGBA (1024, 1536) (...,0)`）；
  - 尺寸是 1024×1536；
  - 道具完整；
  - 没有可读文字；
  - 衣襟是右衽。
  - **区分度**：把新图和已有立绘一起缩到 200 像素宽拼成一张对照图，确认能一眼分清谁是谁；道具和主色不能和别人撞。
- 在 `03_素材/人物立绘/三国立绘/README.md` 的登记表里记一笔：文件、人物、工具、日期、主标志及出处。
- 在 `people-<系列>.yaml` 里补一行 `名字: {image: 03_素材/人物立绘/<id>.png, title: …}`。
- 画面一律标注"AI生成示意像"（组件会自动显示），不代表真实相貌。
- 只有用户主动要求重做时，才替换已有立绘；旧图改名加 `-v1` 保留，不要覆盖。
